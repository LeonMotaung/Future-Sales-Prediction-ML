About This Project

This project utilizes a machine learning model to predict future sales based on advertising budgets for TV, radio, and newspapers. The model is trained on a dataset of past advertising expenditures and their corresponding sales outcomes.

The front-end is built with HTML and Tailwind CSS, and it communicates with a Flask back-end. The back-end serves the machine learning model and provides predictions via a REST API.
